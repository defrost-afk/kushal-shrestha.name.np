# Kushal Shrestha — Portfolio

This is a simple, fast, static portfolio site for your domain `kushal-shrestha.name.np`.

## Files

- `index.html` — main page
- `styles.css` — styling
- `script.js` — theme toggle + mobile menu + reveal animations
- `assets/logo-kushal.svg` — your logo (also used as favicon)

## Edit your info

Open `index.html` and update:

- Email: `you@example.com`
- Social links: GitHub / LinkedIn / Kaggle
- Projects: titles, descriptions, and links
- CV: replace `resume.pdf` with your real CV file (or remove the button)

## Run locally (Windows)

Option A (recommended): install the VS Code extension **Live Server**, then right-click `index.html` → “Open with Live Server”.

Option B: use Python (if installed):

```bash
cd "C:\Users\kushal\OneDrive\Desktop\Web development\portfolio"
python -m http.server 5500
```

Then open `http://localhost:5500`.

## Deploy to your domain

Upload the contents of the `portfolio/` folder to your hosting provider (cPanel / FTP / GitHub Pages / Netlify).
The key is that `index.html` must be at the **web root** (e.g., `public_html/index.html`).
