Supabase Setup Guide

Follow these steps to connect this dashboard to your free Supabase database. This only needs to be done once.

  1. Go to supabase.com and create a free account.
  2. Create a new project. Choose a region close to Nepal (e.g. Singapore).
  3. In the left sidebar go to SQL Editor → New Query.
  4. Paste the contents of schema.sql (provided with this dashboard) and click Run.
  5. Go to Settings → API and copy your Project URL and anon public key.
  6. Click the button below and enter those credentials.
