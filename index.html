Supabase Setup Guide

Follow these steps once to connect your database.

  1. Go to supabase.com and create a free account.
  2. Create a new project. Choose Singapore as the region.
  3. Go to SQL Editor → paste schema.sql → click Run.
  4. Go to Settings → API and copy your Project URL and anon key.
  5. Click the button below and enter those credentials.
